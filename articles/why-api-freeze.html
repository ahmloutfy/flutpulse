Why your API calls freeze your Flutter UI 🚫

Introduction

One of the most frustrating issues in Flutter is when your app suddenly feels stuck… Buttons stop responding, scrolling becomes laggy, and the whole UI freezes. In most cases, the problem isn’t Flutter itself — it’s how API calls are handled.

The Problem ⚠️

void fetchData() {
  var data = api.getData();
  setState(() {
    result = data;
  });
}

This blocks the UI thread.

Why this happens 🔍

  • Flutter runs UI on a single thread
  • Heavy work blocks rendering
  • UI freezes until execution ends

The Solution ✅

Future<void> fetchData() async {
  final data = await api.getData();

  setState(() {
    result = data;
  });
}

Better UX ⚡

bool isLoading = false;

Future<void> fetchData() async {
  setState(() => isLoading = true);

  final data = await api.getData();

  setState(() {
    result = data;
    isLoading = false;
  });
}

Pro Tip 🚀

compute()

Use isolates to keep UI smooth.

Key Takeaway 🎯

If your app freezes, you're blocking the UI thread.
